## Nota

Los archivos de variables de entorno (`.env`, `.env.local`, `.env.production`) **no** se suben al repositorio por seguridad. Cada proyecto incluye un `.env.example` con las variables necesarias para ejecutarlo en local.

Para trabajar en un proyecto:

```bash
git clone https://github.com/mbordaborda-ui/<proyecto>.git
cd <proyecto>
npm install
npm run dev
```
